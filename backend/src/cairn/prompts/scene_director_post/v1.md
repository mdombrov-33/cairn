## Your decision
Return ONLY JSON with this exact shape:
{"combat_ended": false, "scene_transition_push": null, "time_advance_hours": 0, "act_progress": false, "tension_delta": 0, "mood": null, "discovered": [], "threads_added": [], "threads_resolved": [], "npc_updates": [], "npc_departures": []}

- combat_ended: true only if the narration clearly ends an active fight (all foes down/fled/surrendered). The combat system is the real authority; this is a safety net. Default false.
- scene_transition_push: set to {"to_location_id": "<id>", "reason": "<short>"} ONLY when the DM's narration moves the party out of this location and into a new one ("...you step out into the cold street and head home"). Otherwise null. You do not know location ids you weren't given — only set this when the destination is unambiguous; otherwise null.
- time_advance_hours: a positive integer ONLY when scene_transition_push is also set AND meaningful in-world time passed in the transition (travel, a night's sleep). Mid-scene narration never advances time — leave 0. If no transition, 0.
- act_progress: true only if the DM narrated the resolution of one of the act's listed core events. Default false.
- tension_delta: a small signed integer (usually -2..2) when the mood of the scene shifted — positive as danger/stakes rise, negative as things settle. 0 if unchanged.
- mood: "quiet" | "charged" | "hostile" | "intimate" only if the scene's mood clearly changed this turn; otherwise null.
- discovered: short factual strings the party learned or noticed WITHOUT a dice roll (a passing remark, something plainly seen). Do NOT include anything gated behind a skill check — the check system records those. Usually [].
- threads_added: new unresolved tensions the turn opened (a question raised, a promise made). Usually [].
- threads_resolved: verbatim strings from the scene's open threads that this turn closed. Usually [].
- npc_updates: [{"npc_id": "<id>", "doing": "...", "agenda": "..."}] for a present NPC whose in-scene behaviour or agenda shifted. Only ids already present. Omit unchanged fields. Usually [].
- npc_departures: ids of present NPCs who left the scene in the narration. Usually [].
