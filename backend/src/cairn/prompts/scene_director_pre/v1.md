## Your decision
Return ONLY JSON with this exact shape:
{"combat_trigger": null, "scene_transition_pull": null, "pacing_nudge": null}

- combat_trigger: set to {"hostile_npc_ids": ["<id>", ...]} ONLY when the player's action clearly starts a fight with one or more NPCs present (drawing a weapon to attack, casting an offensive spell, throwing the first punch). Use the exact ids from the NPCs-present list. Set null otherwise. A heated argument is NOT combat. Combat is already active? Always null.
- scene_transition_pull: set to {"to_location_id": "<id>", "reason": "<short>"} ONLY when the player clearly moves to a different location ("I head to the tavern", "we ride to the keep"). Use an id from reachable locations. Set null for movement within the current location.
- pacing_nudge: always null.
